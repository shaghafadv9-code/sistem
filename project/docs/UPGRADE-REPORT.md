## 2) الميزات المضافة (مطابقة للطلب البالغ 31 قسمًا)

- **إدارة الديمو** (إعدادات ← البيانات التجريبية، مدير فقط): عدّادات تجريبي/إنتاجي لكل جدول + تاريخ البذر + حذف ذكي مرتب آمن + حماية من الحذف عند وجود سجلات إنتاجية مرتبطة (رسالة عربية تفصيلية) + إعادة تعيين (حذف + بذر جديد) + تأكيد بكلمة مكتوبة. الحسابات/الأدوار/الإعدادات/التدقيق لا تُمس أبدًا.
- **طبقة مزودي AI** (`server/ai.js`): تجريد موحد لـ OpenAI / OpenRouter / Anthropic / Gemini / Ollama المحلي / متوافق مخصص — إضافة مزود جديد = صف واحد في السجل.
- **حماية المفاتيح**: AES-256-GCM بمفتاح جهاز (صلاحيات 0600) + عرض مقنّع فقط + تعقيم تلقائي لأي أثر مفتاح في الأخطاء (بما فيها صدى المزود) + تدقيق لكل عملية + تحديد معدل.
- **نظام التحقق 3-B**: اختبار اتصال + مزامنة موديلات مع تحقق من الشكل + فحص per-model + فحص شامل + اعتماد الافتراضي **مشروط بفحص ناجح** + بديل تلقائي + تشخيص + ملعب + سجل استهلاك + أخطاء مصنفة (AUTH/NOT_FOUND/RATE_LIMIT/TIMEOUT/NETWORK/SERVER).
- **المساعد داخل النظام**: محلي (بطاقات + تأكيد) ← يترقى تلقائيًا لنموذج AI عند توفره، بسياق **مفلتر بالصلاحيات** (إحصاءات إجمالية فقط، بلا PII).
- **الهوية المركزية**: ألوان/خط/شعار/تذييل/سطر تعريفي — تُطبق فورًا على القائمة والدخول والتقارير المطبوعة وExcel.
- **القوالب**: `{{متغيرات}}` + قاموس متغيرات + إدراج بالنقر + تجربة حية تُظهر النواقص.
- **الوسطاء** (صفحة + صلاحيات): CRUD + كشف عمولات + صرف مستحقات بتحقق + عمولة تلقائية من نسبة الوسيط عند البيع.
- **الخط الزمني**: عميل/وحدة/بيع — مبيعات وحجوزات ودفعات وفواتير واتصالات ومواعيد وملاحظات وملفات.
- **المرفقات**: ربط الملفات بأي كيان (عميل/وحدة/مشروع/بيع/حجز/مهمة/موعد) من داخل نوافذ التفاصيل.
- **البحث الشامل Ctrl+K**: يشمل الآن المبيعات والحجوزات والفواتير والدفعات والوسطاء + إجراءات سريعة (إصلاح خلل توجيه الإجراءات أيضًا).
- **اللوحة المخصصة**: 9 ودجت لكل مستخدم + عنصر متابعات + رسم اتصالات.
- **المتابعات**: buckets (متأخرة/اليوم/قادمة/اتصالات/حجوزات منتهية) في المهام واللوحة.
- **التقارير**: ترويسة Excel بألوان الهوية + شعار في المطبوعات + **مولّد تقارير AI** (قراءة فقط).
- **النسخ**: مركز + جدولة يومية تلقائية + حد احتفاظ.
- **الصحة والصيانة**: قراءات حية (DB/ملفات/ذاكرة/تشغيل/AI) + وضع صيانة (المدير يعمل، البقية تُحجب، الدخول والهوية متاحان).
- **الأمان**: تحديد معدل (عام/دخول/AI) + منع الملفات التنفيذية + تحقق IDs + منع overpay/over-payout + فحص صلاحيات خلفي على كل مسار جديد.
- **سلامة قاعدة البيانات (اكتشاف حرج)**: تفعيل `foreign_keys` فعليًا بعد اكتشاف أن `export()` في sql.js يُصفّره — مع ترتيب حذف آمن.

## 3) حالة AI API (بوابة 3-B)

- **لفحوصات الحية (لحظة الاختبار): `AI API: FAILED (AUTH)` كما هو متوقع بمفتاح وهمي** — التصنيف صحيح والتعقيم مُتحقق (لا أثر للمفتاح في أي رد).
- **الحالة الحالية للنظام المسلَّم: `NOT_CONFIGURED`** — لا مزودون (حُذف مزود الاختبار)، صفر مفاتيح.
- **التفعيل (دقيقتان من الواجهة، بدون أوامر):** الإعدادات ← الذكاء الاصطناعي ← مزود جديد ← (النوع + المفتاح) ← اختبار الاتصال ← (مزامنة تلقائية) ← فحص الموديل ← اعتماد ← يعمل المساعد والملعب والتقارير الذكية فورًا. Ollama المحلي يعمل **بدون مفتاح**.
